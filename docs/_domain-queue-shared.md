One of the easiest options for adding domains is to use the Domain Queue, which allows you to supply a list of domains and let DomainMOD take care of the rest (and in some cases you don't even need to supply the list of domains, it will be automatically retrieved from your registrar account).

If your registrar has an API that DomainMOD supports, the Domain Queue uses it to retrieve the information required to add your domains, so before using this option make sure your API credentials have been saved with your registrar account. If your registrar isn't supported, you can still paste in a list of your domains, and DomainMOD will look up their details using RDAP, the public replacement for WHOIS, or WHOIS itself for domains that RDAP doesn't cover.
